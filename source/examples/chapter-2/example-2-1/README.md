# Example 2.1 — Student identity and date

For PHP/HTML examples, serve this folder using PHP 8.3: `php -S localhost:8000`. Visit http://localhost:8000/main.php.

## Explanation

Double-quoted strings interpolate variables. Setting a timezone makes the date display intentional.

## Reference result

```text
Asha | BCA Semester VI
Current date and time in Asia/Kolkata
```

## Try this

Change the name and date format. Compare date("Y-m-d") with date("d/m/Y").
