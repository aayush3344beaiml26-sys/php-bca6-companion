# Example 6.1 — Quoting and heredoc

For PHP/HTML examples, serve this folder using PHP 8.3: `php -S localhost:8000`. Visit http://localhost:8000/main.php.

## Explanation

Single quotes keep $name literal. Double quotes and heredoc substitute the variable’s value.

## Reference result

```text
Hello $name
Hello Asha
Course: BCA
Student: Asha
```

## Try this

Add another interpolated variable to the heredoc.
