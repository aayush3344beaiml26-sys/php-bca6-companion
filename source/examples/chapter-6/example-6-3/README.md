# Example 6.3 — Normalise text case

For PHP/HTML examples, serve this folder using PHP 8.3: `php -S localhost:8000`. Visit http://localhost:8000/main.php.

## Explanation

The ASCII case functions return changed copies. ucwords after strtolower gives simple title-style casing for this example.
