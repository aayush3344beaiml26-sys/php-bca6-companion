# Example 4.1 — A reusable percentage function

For PHP/HTML examples, serve this folder using PHP 8.3: `php -S localhost:8000`. Visit http://localhost:8000/main.php.

## Explanation

The function receives two values and returns a number. It rejects a denominator that would make the calculation invalid.

## Reference result

```text
72.00%
```

## Try this

Call it for 378 out of 500; then catch the exception for maximum 0.
