# Example 8.1 — Connect with MySQLi

For PHP/HTML examples, serve this folder using PHP 8.3: `php -S localhost:8000`. Visit http://localhost:8000/main.php.
Start MySQL/MariaDB and import schema.sql first. Configure the host/user/password for your installation. Default credentials are for a private local teaching setup.

## Explanation

Strict MySQLi reporting turns failures into exceptions. The catch logs details privately while the visitor sees a general message.

## Reference result

```text
Database connected. (with the configured local database running)
```

## Try this

Stop MySQL and verify the error branch. Configure a dedicated database user before sharing the application.
