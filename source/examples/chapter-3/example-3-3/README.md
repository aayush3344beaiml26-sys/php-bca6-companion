# Example 3.3 — Multiplication table

For PHP/HTML examples, serve this folder using PHP 8.3: `php -S localhost:8000`. Visit http://localhost:8000/main.php.

## Explanation

The counter starts at 1, is tested before each iteration, and increments after the body.

## Reference result

```text
7 × 1 = 7
7 × 2 = 14
7 × 3 = 21
7 × 4 = 28
7 × 5 = 35
```
