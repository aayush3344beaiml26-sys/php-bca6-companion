Chapter 1 · Introduction to Server-Side Scripting and PHP

Practice questions

1. [Explain] Trace a request for http://localhost/course/index.php from the browser to the displayed page.
Hint and suggested answer

Hint: Name the browser, web server and interpreter.

The browser sends an HTTP request to the local web server. The server maps the URL to index.php, passes it to PHP, and returns the generated response. The browser renders the HTML response.

2. [Apply] A PHP file opens as text when double-clicked. Give a diagnosis and a correction.
Hint and suggested answer

Hint: Examine the URL scheme.

It was opened with file:// or a server without PHP support. Start the PHP-capable web server and request the file through http://localhost/project/file.php.

3. [Compare] Can a static page contain an interactive menu? Explain.
Hint and suggested answer

Hint: Separate response generation from browser behaviour.

Yes. A prewritten HTML response can include JavaScript that handles a menu in the browser. That interaction does not require server-side generation.

4. [Debug] localhost returns 404 for hello.php even though Apache is running. What should you check?
Hint and suggested answer

Hint: Check the mapping between disk and URL.

Verify the configured document root, project folder, filename including case, and URL path. Also check that the request is reaching the intended server and port.

5. [Build] Create a course welcome page with a fixed heading and a PHP-generated student greeting.
Hint and suggested answer

Hint: Use HTML around a PHP block.

Keep the fixed heading in HTML. Read a name with a default, escape it with htmlspecialchars, and echo it inside the greeting. Test a missing name and a name containing <.

6. [Viva] Why does View Source usually not show the original PHP statements?
Hint and suggested answer

Hint: Consider where execution happens.

PHP executes on the server before the response is sent. View Source shows the response body, which normally contains generated HTML rather than PHP source.

Chapter 2 · PHP Basics

Practice questions

1. [Predict] What does echo 7 + 2 * 3; display? What if it is echo (7 + 2) * 3;?
Hint and suggested answer

Hint: Multiplication binds first.

The first expression displays 13. The parenthesised expression displays 27.

2. [Debug] Repair: name = "Asha"; echo $Name;
Hint and suggested answer

Hint: Check variable syntax and case.

$name = "Asha"; echo $name; Variable names need $ and must use consistent letter case.

3. [Build] Calculate a bill for 3 items at ₹125.50 each with 5% GST. Display two decimal places.
Hint and suggested answer

Hint: Compute subtotal, tax, then total.

Subtotal = 376.50; GST = 18.825; total = 395.325. number_format($total, 2) displays 395.33 with normal PHP rounding. Keep unrounded values until display.

4. [Explain] Compare echo and print in terms of return value and arguments.
Hint and suggested answer

Hint: Both are language constructs.

echo has no return value and accepts multiple comma-separated expressions. print accepts one expression and returns 1. Both write output.

5. [Apply] Define a fixed maximum score and calculate a percentage from a variable mark.
Hint and suggested answer

Hint: Use const for the maximum.

const MAX_SCORE = 80; $mark = 60; $percentage = $mark / MAX_SCORE * 100; gives 75. Validate that marks are within range before calculation.

6. [Viva] Why should a form value "0" not be checked only with if ($value)?
Hint and suggested answer

Hint: Consider falsy values.

The string "0" is falsy in PHP. Test whether the key exists and validate its value explicitly rather than treating false-like values as missing.

Chapter 3 · Control Structures

Practice questions

1. [Trace] Trace $i=1; while($i<5){ echo $i; $i+=2; }
Hint and suggested answer

Hint: List $i before every condition test.

Tests occur with 1, 3 and 5. The body prints 1 and 3, so the output is 13.

2. [Build] Classify a mark: 75+ Distinction, 60–74 First, 40–59 Pass, below 40 Fail. Reject values outside 0–100.
Hint and suggested answer

Hint: Reject invalid values before grade selection.

Check $mark < 0 || $mark > 100 first. Then use descending thresholds >=75, >=60, >=40, else Fail. Test -1, 0, 39, 40, 59, 60, 74, 75, 100 and 101.

3. [Debug] Why does if ($marks = 40) always appear to pass?
Hint and suggested answer

Hint: An assignment expression also has a value.

= assigns 40, whose truth value is true. Use $marks >= 40 for a pass threshold or $marks === 40 for strict equality.

4. [Build] Find the sum of even integers from 1 to 20 using a loop.
Hint and suggested answer

Hint: Either step by 2 or test the remainder.

Set $sum=0; for($i=2;$i<=20;$i+=2){$sum+=$i;} The result is 110.

5. [Compare] When can do-while run once while while runs zero times?
Hint and suggested answer

Hint: Consider an initially false condition.

while checks first and skips its body when false. do-while executes the body first and checks afterwards, so it performs at least one iteration.

6. [Viva] How would you recognise and repair an infinite while loop?
Hint and suggested answer

Hint: Identify what changes the condition.

Trace the variables used in the condition. Ensure the body updates them toward termination on every relevant path; a continue before the update can prevent this.

Chapter 4 · Functions

Practice questions

1. [Build] Write a function that converts Celsius to Fahrenheit and returns the result.
Hint and suggested answer

Hint: Use F = C × 9/5 + 32.

function fahrenheit(float $c): float { return $c * 9 / 5 + 32; } Check 0 → 32 and 100 → 212.

2. [Explain] Distinguish formal and actual parameters using add(4, 6).
Hint and suggested answer

Hint: One belongs to the definition; one to the call.

In function add($a,$b), $a and $b are formal parameters. In add(4,6), the supplied arguments 4 and 6 are actual parameters.

3. [Debug] A function echoes a total, but $result = total(2,3) gives null. Why?
Hint and suggested answer

Hint: A displayed result is not a returned result.

Without return, a function normally returns null. Replace echo with return $a + $b; and display the returned value at the call site.

4. [Apply] A required database configuration is missing. Choose include or require and justify.
Hint and suggested answer

Hint: Should the application continue without configuration?

Use require (usually require_once) because the application cannot work correctly without its configuration. Handle failures at an appropriate boundary rather than silently proceeding.

5. [Build] Use a shared footer on two PHP pages. Make the path independent of the current working directory.
Hint and suggested answer

Hint: Build the path with __DIR__.

Place footer.php beside the pages and use include __DIR__ . "/footer.php"; in each page. __DIR__ is the directory of the file containing that expression.

6. [Viva] When should a function return a value instead of printing it?
Hint and suggested answer

Hint: Think of testing and reuse.

Return when callers need to calculate with, validate, test or format the result. Printing ties the function to one output format and makes reuse harder.

Chapter 5 · Arrays

Practice questions

1. [Build] Store three products with name and price, then print a total.
Hint and suggested answer

Hint: Use a list of associative arrays.

Create $products = [["name"=>"Notebook","price"=>50], ...]; start $total=0 and add each row’s price inside foreach. Use number_format for display.

2. [Modernise] Replace while (list($key,$value) = each($data)) { echo "$key: $value"; }.
Hint and suggested answer

Hint: The replacement needs no internal pointer.

foreach ($data as $key => $value) { echo "$key: $value"; } each() is unavailable in PHP 8.

3. [Debug] A largest-value function starts with $largest=0 and receives [-9,-2,-5]. Why is its answer wrong?
Hint and suggested answer

Hint: Does the initial candidate belong to the input?

Zero is larger than every input but is not an input element. Initialise from the first existing value and reject or otherwise handle an empty array. The correct result is -2.

4. [Predict] After $a=[10,20,30]; next($a); end($a); prev($a); what does current($a) return?
Hint and suggested answer

Hint: Track the internal pointer.

20. next selects 20, end selects 30, and prev returns to 20.

5. [Compare] Choose sort, asort or ksort for student-name keys ordered by ascending marks.
Hint and suggested answer

Hint: The relationship between names and marks must remain intact.

Use asort. sort reindexes the values and loses the name keys; ksort orders by names rather than marks.

6. [Viva] Why is if(array_search("PHP",$subjects)) unreliable?
Hint and suggested answer

Hint: Consider a match at index 0.

Index 0 is falsy, so the condition misclassifies the first element as missing. Store the result and compare it with !== false, preferably using strict search mode.

Chapter 6 · Strings

Practice questions

1. [Predict] What does strlen("BCA PHP") return?
Hint and suggested answer

Hint: Spaces also occupy bytes.

7 for this ASCII string: three letters, one space, and three letters.

2. [Build] Normalise " bca-vi " to "BCA-VI".
Hint and suggested answer

Hint: Clean the ends before changing case.

$code = strtoupper(trim(" bca-vi ")); The result is BCA-VI.

3. [Debug] Why does if(strpos($text,"PHP")) fail when $text begins with PHP?
Hint and suggested answer

Hint: The successful result can be zero.

strpos returns integer 0 for a match at the beginning, which is falsy. Use strpos($text,"PHP") !== false.

4. [Build] Split "PHP,SQL,HTML" and display one subject per line.
Hint and suggested answer

Hint: Turn the string into a collection first.

foreach (explode(",", $text) as $subject) { echo trim($subject) . "\n"; } Trim handles optional spaces around separators.

5. [Explain] Does trim make a submitted name safe to insert inside HTML?
Hint and suggested answer

Hint: Cleaning and output encoding solve different problems.

No. trim only removes specified edge characters. Use htmlspecialchars($name, ENT_QUOTES, "UTF-8") when inserting the name into an HTML text or quoted attribute context.

6. [Viva] Why might strlen report more bytes than the number of letters in an Indian-language name?

Hint: Recall UTF-8 representation.

UTF-8 encodes many characters using multiple bytes. strlen counts bytes rather than letters or grapheme clusters. Choose mb_strlen or a grapheme-aware function for the actual requirement.

Chapter 7 · Working with Forms and User Input

Practice questions

1. [Compare] Choose a method for a shareable catalogue search and for submitting a registration.
Hint and suggested answer

Hint: One retrieves; the other changes state.

Use GET for a bookmarkable retrieval query and POST for registration. Use HTTPS for both when carrying sensitive data. POST alone does not encrypt data.

2. [Debug] Why is an input with id="email" but no name absent from $_POST?
Hint and suggested answer

Hint: The label connection and submitted key are different attributes.

Successful form controls are submitted using their name attribute. Add name="email"; id only identifies the element in the document.

3. [Build] Validate an age as an integer from 18 to 60, including both endpoints.
Hint and suggested answer

Hint: Distinguish false from integer zero.

Use filter_var($raw, FILTER_VALIDATE_INT, ["options"=>["min_range"=>18,"max_range"=>60]]) and compare the result with === false. Reject invalid data before storage.

4. [Explain] Why must validation still run in PHP when the HTML input has required and type="email"?
Hint and suggested answer

Hint: A request can be made without your form.

Users and tools can bypass or alter client-side constraints. Only the server can enforce the application’s validation rules for all incoming requests.

5. [Test] Design six upload tests for the image handler.
Hint and suggested answer

Hint: Include failures at different stages.

Test a small valid JPEG, valid PNG, no file, file above 2 MB, text renamed .jpg, and an unwritable storage directory. Verify clear failure messages and no partial saved file.

6. [Viva] What is the difference between validating a name and escaping it?
Hint and suggested answer

Hint: Meaning versus output context.

Validation decides whether the name satisfies application rules. Escaping represents accepted text safely in its output context; HTML escaping prevents input from becoming markup.

Chapter 8 · Database Connectivity

Practice questions

1. [Explain] Why is SELECT * FROM students WHERE name = '$name' unsafe with request input?
Hint and suggested answer

Hint: Input can become SQL syntax.

A crafted name may alter the query structure. Use SELECT ... WHERE name = ? with a prepared statement and bind the name as a string. Validate according to the application’s rules as well.

2. [Build] Write a prepared INSERT for roll_no, name and email.

3. [Debug] A connection succeeds but Indian-language text appears corrupted. What should be checked?
Hint and suggested answer

Hint: Consider the entire encoding path.

Use utf8mb4 for database/table columns and call $db->set_charset("utf8mb4"). Serve HTML as UTF-8 and verify the source data was stored correctly rather than merely changing its display.

4. [Apply] An update reports affected_rows = 0. Give two possible explanations.
Hint and suggested answer

Hint: A successful query need not change a record.

No row matched the WHERE condition, or the matching row already contained the supplied value. Check whether the row exists if the interface must distinguish these cases.

5. [Test] Design tests for a student registration form backed by a UNIQUE roll number.

Test a valid registration, missing name, invalid email, duplicate roll, an HTML-like name, and a database outage. Check stored values, safe output and useful messages without credential leakage.

6. [Viva] Why should a database exception be logged instead of echoed in full?
Hint and suggested answer

A raw exception can reveal schema, hostnames and operational details. Log it for diagnosis and return a general user-facing message with an appropriate response status.

Chapter 9 · Sessions and Cookies

Practice questions

1. [Explain] Why does $_COOKIE["theme"] not immediately contain a value just passed to setcookie?
Hint and suggested answer

Hint: Requests and responses are separate.

$_COOKIE contains cookies received with the current request. setcookie adds a response header for the browser to process and return with a later matching request.

2. [Build] Create a cookie that lasts 7 days and is available across the site.
Hint and suggested answer

Hint: Seconds determine the expiry; path determines scope.

Use setcookie("preference", "compact", ["expires"=>time()+7*24*60*60,"path"=>"/","httponly"=>true,"samesite"=>"Lax","secure"=>true]) on HTTPS, before output. For plain localhost, Secure requires adjustment.

3. [Debug] Why does echo "Welcome"; session_start(); risk a headers-already-sent warning?
Hint and suggested answer

Hint: The session may need to send a cookie.

Output may commit HTTP response headers before session_start tries to send session headers. Start the session before any output, including whitespace in included files.

4. [Compare] Where is a typical session value stored, and where is an ordinary cookie value stored?
Hint and suggested answer

Hint: Distinguish the session identifier from its data.

Session values are stored on the server using the configured handler. The browser usually holds only their session identifier. Ordinary cookie values are stored in the browser and returned in matching requests.

5. [Apply] A cookie created with path=/course remains after deletion with path=/. Explain.
Hint and suggested answer

Hint: Cookie identity includes scope.

Those paths identify different scoped cookies. Expire the cookie using its original name, path and domain; the browser must receive that deletion response.

6. [Viva] What should happen to the session identifier after a successful login?
Hint and suggested answer

Hint: A pre-login identifier should not carry over unchanged.

Regenerate it, commonly with session_regenerate_id(true), after authentication to reduce session fixation risk. Also use appropriate session cookie attributes and access controls.

Quick quiz

1. Which starts or resumes a PHP session?
  1. session_open_page()
  2. session_start()
  3. start_cookie()
  4. $_SESSION()
Answer and explanation

B. session_start activates the session and reads its stored data.

2. Where do typical PHP session values live?
  1. In the CSS file
  2. In server-side session storage
  3. Only in the URL
  4. Inside every HTML element
Answer and explanation

B. The browser generally carries the identifier, not the full session data.

3. When should setcookie normally be called?
  1. After all HTML
  2. Before output is sent
  3. Only in JavaScript
  4. After closing the database
Answer and explanation

B. It sets response headers, which must precede the response body.

4. Does session_encode encrypt data?
  1. Yes
  2. No
Answer and explanation

B. It serialises the session using the configured format; serialisation is not encryption.

5. How is a cookie normally deleted?
  1. Set its expiry in the past with matching scope
  2. Unset a local variable only
  3. Refresh the page
  4. Call trim on its value

Chapter 10 · Error and Exceptional Handling

Practice questions

1. [Classify] A script has a missing semicolon, reads an absent array key, then divides by zero. Do these all fail in the same way?
Hint and suggested answer

Hint: Consider parsing versus execution.

No. A missing semicolon can cause a parse error before execution. An absent array key normally raises a warning in PHP 8. Division by zero can throw DivisionByZeroError. The first encountered failure may prevent later statements from running.

2. [Build] Throw a custom InvalidAgeException for an age below 18, then catch it.
Hint and suggested answer

Hint: Extend Exception and throw an instance.

class InvalidAgeException extends Exception {} if($age<18){throw new InvalidAgeException("Minimum age is 18");} Put the check in try and catch InvalidAgeException to display a suitable message.

3. [Debug] Why is catch(Throwable $e) before catch(InvalidArgumentException $e) a problem?
Hint and suggested answer

Hint: The first compatible handler wins.

Throwable already matches InvalidArgumentException, so the later specific catch cannot handle it. Put specific types first and a broad fallback last.

4. [Explain] Will catch(Exception $e) automatically catch an undefined array key warning?
Hint and suggested answer

Hint: A warning is not an exception object by default.

No. Ordinary warnings are not automatically Exception objects. Prevent the missing-key access with a deliberate default or existence check. An explicit error handler can convert selected warnings when appropriate.

5. [Test] List tests for a division function that rejects a zero divisor.
Hint and suggested answer

Hint: Cover successful and exceptional paths.

Test positive divisor, negative divisor, zero numerator with non-zero divisor, zero divisor, and fractional values. Verify returned results, exception type, message and cleanup behaviour.

6. [Viva] What is a useful debugging sequence after a student reports a blank page?
Hint and suggested answer

Hint: Collect evidence before changing unrelated code.

Reproduce with the same input and environment, inspect the server error log, locate the failing line, isolate a small case, fix the cause, and retest the failing case plus nearby valid and invalid cases.
